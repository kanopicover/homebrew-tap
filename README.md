# kanopicover/homebrew-tap

Homebrew tap for Kanopi CLI packages.

```bash
brew install kanopicover/tap/cov
```

`cov-mcp` is not on this tap yet. It joins on the GAP-587 S5 tag that allow-lists that crate.

Formula `url` values are public CloudFront objects on `https://downloads.kanopi-dev.com/cli/{tag}/`. cargo-dist publishes formulae from [covenant](https://github.com/kanopicover/covenant) `cov-v*` tags.

See [Install cov](https://docs.kanopi-dev.com/tools/cov/install).
