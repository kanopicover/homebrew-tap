# kanopicover/homebrew-tap

Homebrew tap for Kanopi CLI packages.

```bash
brew install kanopicover/tap/cov
brew install kanopicover/tap/cov-mcp
```

Formula `url` values are public CloudFront objects on `https://downloads.kanopi-dev.com/cli/{tag}/`. cargo-dist publishes formulae from [covenant](https://github.com/kanopicover/covenant) `cov-v*` and `cov-mcp-v*` tags.

See [Install cov](https://docs.kanopi-dev.com/tools/cov/install) and [cov-mcp](https://docs.kanopi-dev.com/tools/cov-mcp/).
